# Immersive First Person
Realistic, usable and customizable first-person view that moves the player right in the character's eyes

## Features
* First-person view: realistic full body and environment view
* Convenient IFP disabling when player is holding sandbox-tools
* Useful customizable dot-crosshair
* Customizable IFP parameters
* View modifiers: Full Immersion and BodyCam Mod (required [Simple Custom Shaders](https://steamcommunity.com/workshop/filedetails/?id=3440271589))
* Customization the view when aiming (Right mouse click)
* EN and RU localization

## Addon settings
All settings are located: `SpawnMenu` -> `Utilities` -> `IFP`

Client console variables:
* `cl_ifp_enable (0/1) Default: 1` - Enable/disable IFP addon
* `cl_ifp_crosshair_enabled (0/1) Default: 1` - Enable/disable dot-crosshair
* `cl_ifp_fov_multiplier [0.75; 1.25] Default: 1.00` - Edit FOV multiplier
* `cl_ifp_znear [1.00; 5.00] Default: 3.00` - Edit view zNear
* `cl_ifp_lock_enabled (0/1) Default: 1` - Enable/disable view angle lock
* `cl_ifp_lock_vertical [75; 90] Default: 80` - Edit vertical view angle lock
* `cl_ifp_force_show_head (0/1) Default: 0` - Enable/disable forced showing head
* `cl_ifp_mod [0; 2] Default: 0` - Set IFP modifier (0: Disabled; 1: Full Immersion; 2: BodyCam Mod)
* `cl_ifp_disable_when_aim (0/1) Default: 1` - Enable/disable view disabling when player aiming (Right mouse click)

Client console commands:
* `ifp_toggle` - Toggle IFP addon (Enable/disable)
* `ifp_reset_settings` - Reset IFP addon settings
* `ifp_weapons_editor` - Open weapons view editor
